The Android app has Code: the coding agents' threads, live. Watch a turn stream, steer it or queue a message, stop it, allow or deny approvals and answer questions, change the model, reasoning and permissions, and start new threads in a directory or a project. Changes shows the diffs (and a project branch's review with line comments), and the pull request screen publishes, runs Auto-fix and merges. Code pushes and a bot's hand-off card open the thread in the app.
