Smoother everyday use. A Settings link opened straight from the address bar, a bookmark or a reload now stays on its section instead of falling back to Appearance. Phone pages show one menu button instead of two. Adding a project in Code makes its chat right away, so it shows up in Chat's sidebar without opening it from Code first.

New chat (the header button, its shortcut and the palette) starts a fresh chat straight away instead of asking first, the same as typing `/new`. The chat you leave stays in Chat history, where you can read or continue it.
