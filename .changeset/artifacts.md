Bots can now write artifacts: a document, code file, diagram, SVG or single HTML page that opens in a panel next to the chat instead of filling the reply. Each change the bot makes is kept as a version, so you can look back at any of them, copy or download it, and restore an old one. HTML and SVG run in a locked-down frame that can't reach your session or the network. Guests of a shared bot can read its artifacts.
