New connections and skills now reach every bot, including bots you make later, so you no longer switch them on bot by bot. A bot can still turn one off, and a connection's or skill's page has an **Every bot** switch to narrow it to the bots you tick. Bots shared with guests get them too, and project chats get them only when ticked. Connections every bot shares always load on demand, so each adds one short line to a request. Existing setups keep exactly what each bot had: a connection or skill every bot already used becomes shared.
