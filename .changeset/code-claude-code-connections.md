Claude Code threads can now use your connections too. Every connection shared with every bot is offered to Claude Code, loaded on demand, and the calls run in the app, so connection sign-ins never reach the sandbox. Settings > Tools decides which tools run, ask or stay off, and a tool that asks shows the usual approval card.
