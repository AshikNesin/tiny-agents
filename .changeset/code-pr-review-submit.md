Code: comment on a pull request's lines in a review and submit the review on GitHub. **Comment** adds to your review, **Ask assistant** asks about the lines, and **Suggest change** starts a GitHub suggestion. **Submit review** posts every comment with a summary and Comment, Approve or Request changes; on your own PR it offers Comment only, and comments on a PR a Code thread opened can go to that thread instead.
