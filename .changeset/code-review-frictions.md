Code: fixes from an end-to-end run against a real GitHub pull request. A draft PR offers **Ready for review**, so it can be merged without a trip to GitHub. When the branch has nothing to publish because the agent's changes aren't committed, the PR tab says so, with **Ask to commit**. A folded turn says when a command in it failed. A project thread's first message shows its branch instead of the agent's instructions, and an Auto-fix request reads as one short card naming what it fixes. A check with no run time no longer shows `0ms`.
