Code Reviews: filter the inbox by how recently a PR was updated, by repository (or projects only), and hide drafts. GitHub's search applies the filters, so they reach past the first 50 PRs, and this browser remembers them. Each row now has its own GitHub link beside it, so a click on the row always opens the review here, and a PR of a repository that is not a project says so.
