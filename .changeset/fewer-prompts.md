Fewer "Confirm it's you" prompts. Replacing a model account's key or a connection's header value, discovering or testing a model endpoint, saving a GitHub token and starting GitHub App setup no longer ask for your password. Adding an account or connection, pointing one somewhere new, and deleting one still do. Saving a GitHub token in Settings works again; it failed every time before.

Bots save memories you ask for without an approval card. Forgetting a memory still asks, and you can set saving back to Ask under Settings > Tools.

A draft pull request now says "Turn Draft off to merge" beside its disabled Merge button, so the reason shows on a phone too.
