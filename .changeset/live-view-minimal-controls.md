The Browser and Computer live views are simpler. The chat panel's header is one row: the Browser / Computer tabs (with icons), one status chip ("Chief is driving", or a pulsing "You're driving") and the tools as icons. The Browser and Computer pages get the same bar over the view, so their tools stay on screen in full screen. Click the stream to take control (hover shows "Click to take control"); a green frame marks it while you drive, and "Hand back" returns it. The header no longer repeats the address bar the streamed Chrome already shows, or the desktop's size.
