Typing `/` in a bot chat or a Code thread now lists your tools as well as commands and skills. Each connection shows up (for example `/github` for every GitHub tool), and as you type you can pick a single tool. A picked tool sits as a chip above the composer, and the message asks the agent to load and use it. The chat menu also offers `/new`, and it opens even for a bot with no skills.
