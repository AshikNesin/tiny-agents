Traces: a session's page now shows the whole interaction, not just which calls ran. Each turn shows the prompt, the model's thoughts and replies, and every tool call, which opens to its input and output, plus where the context was summarized. A sidebar counts prompts, agent responses, thinking, tool calls (per tool) and compactions and filters the transcript to the ones you check; on a phone it folds under Filter. Everything is read from the conversation's stored entries; nothing new is stored.
