# Behavior register

Each row below is a current behavior that looks like a bug or a quirk. The
default is **Preserve**: the rewrite reproduces it exactly, and Phase 0 pins
it with a characterization test. A row changes only when the owner sets it to
**Fix** (or **Fix first**, on today's code, before the rewrite starts). Every
Fix lands as its own PR that names the row and updates only that row's
goldens.

Rows were found by reading the code, and only P1/P3 have been run. A row that
its characterization test cannot reproduce is marked _not real_ here, not
silently dropped.

Legend:

- **Rec.** is my recommendation.
- **Owner** is the owner's decision. On 2026-11-14 the owner accepted every recommendation (tracking issue #247).
