I built Tiny Agents to solve my own problems, and I think everyone should have a personal assistant they fully control.

Your data stays in SQLite files on your machine, you pick the model provider, and you decide what each bot may do without asking.

What a bot can do

Ask before acting

Set each tool to Allow, Ask or Off. Approve from the web app, a push notification or the Android app.

Use a real browser and computer

A bot drives its own Chrome and, on a sandbox VM, a full desktop. You can watch live and take over.

Run on a schedule

Routines run a bot's prompt once, daily, weekly or on an interval, and report back.

Remember you

Per-bot memory, and a vault that fills logins and cards without the model seeing them.

Connect your tools

Add any remote MCP server.

Hand off code

The Code page drives coding agents (Claude Code, Shelley) and their pull requests.

Try it in two minutes.

No account with us and no hosted tier. You need Node.js 24 and pnpm 10. 

git clone https://github.com/AshikNesin/tiny-agents.git
cd tiny-agents
pnpm install
TINY_AGENTS_FAUX=1 pnpm dev

Questions

How do I try it?
Clone it from GitHub and run it with the built-in test model, as above. Add a real model in Settings when you're ready.
Is there a hosted version?
No. You run it yourself, on a small server or your own machine, so your chats, memories and secrets stay with you.
Is it one assistant or several?
Start with one. If you want, add specialists like a travel planner or a code helper, each with its own personality, model and tools. They can hand work to each other.
Which models does it use?
The ones you already pay for: Anthropic, OpenAI, Gemini, any OpenAI-compatible host, Cloudflare AI Gateway or your Claude plan.
Can it spend money without asking?
No. A saved card asks for your OK every time it's used, and the model never sees the number.
Is there a phone app?
Yes, for Android. It does what the web app does, with push notifications you can approve from. It's coming to the Play Store soon; until then, download the APK.
What's the license?
MIT. Use it, change it, run it wherever you like.
