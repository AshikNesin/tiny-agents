Features

Built to act, and to ask first.

Each agent has its own persona, model and tools. You decide what each one may do on its own.

Memory

Remembers your preferences across chats. You can read and edit everything it knows.

Browser use

Opens real websites in its own browser. Watch it live, or take over with one click.

Computer use

Each agent gets its own desktop on a sandbox machine, never yours, and can run commands there.

Approvals

Reading is automatic. Anything that spends money or changes something waits for your yes.

Vault

Passwords, keys and cards go straight into the page or request. The agent never sees them.

Permissions

Set every tool to Allow, Ask or Off, per agent.

MCP

Connect calendars, email, docs or any remote MCP server, and choose which agents use it.

Routines

Set up recurring work in plain words. Agents message you first when something changes.

A team

Agents hand work to each other. Mention one with @ and it picks up the job.

Self-host

Runs on your server.

One Node process and two SQLite files. Conversations are durable: refresh mid-reply, restart the server or redeploy, and the reply picks up where it left off.

  • RuntimeNode 24, one process
  • StorageSQLite: app.db and agent.db
  • ModelsClaude, GPT and more via Cloudflare AI Gateway
  • Provider keysStay in the gateway
  • Sign-inPassword or passkey
