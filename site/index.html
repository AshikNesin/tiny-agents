Built to act, and to ask first.

Each agent has its own persona, model, memory and tools.

Memory

Remembers your preferences across chats. You can read and edit all of it.

Browser and computer

Each agent gets a real browser and its own sandbox desktop, never yours. Watch live or take over.

Approvals

Every tool is Allow, Ask or Off, per agent. Asks arrive as a card you approve or deny.

Vault

Passwords, keys and cards are filled in for the agent. It never sees them.

Routines and alerts

Recurring work in plain words. A push when an agent needs you or finishes a job.

MCP and teamwork

Connect calendar, email and docs over MCP. Mention another agent with @ to hand it the job.

Runs on your server.

One Node process and two SQLite files. Conversations are durable: refresh mid-reply, restart or redeploy, and the reply picks up where it left off.

Questions

When can I try it?
Tiny Agents will be open sourced soon. Follow @AshikNesin on X to hear the moment it ships.
Is there a hosted version?
No. You run it yourself, so your chats, memories and secrets stay on your machine.
Which models does it use?
Any model you have access to, such as Claude or GPT. Route them through Cloudflare AI Gateway or call a provider directly, and pick a model per agent.
Can an agent spend money without asking?
Only if you allow it. Payments and anything that changes something default to Ask, and card details come from the Vault, so the agent never sees them.
